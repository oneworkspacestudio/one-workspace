# Reinstall One Workspace

From Workspace administration, open **Updates and backups**, choose **Check for
updates**, then **Back up and reinstall Workspace**. The latest verified installer
downloads and runs automatically. It saves a recovery copy and restarts your apps;
the results show any apps needing attention and link to their retry page. This
action repairs recognised installations and never resets account setup.

You can also use a downloaded installer:

Open the latest Workspace installer. Choose **Already have One Workspace? Update
or reinstall**, enter your existing Workspace folder and choose **Reinstall in
this folder**. You can also choose that folder during normal setup.

Tick **Reinstall in this folder and save a recovery copy first**, then continue.
Setup shows what it will keep before you choose **Reinstall Workspace**.

If your Workspace account setup is complete, your accounts, app data, Files,
connection settings and app choices stay in place. Setup verifies replacement
program files, pauses the apps, saves a recovery copy and reinstalls the programs.
You can do this even if the version has not changed or a program is missing.
Apps installed separately at a newer version are kept.

If an earlier setup stopped before it could save a complete account setup, the
installer explains that sign-in setup will start again. Your ordinary Files folder
stays in place. The previous Apps and Private folders are saved in a protected
**ReinstallRecovery** folder beside them before the new setup starts. Keep this
recovery folder if you need to recover previous accounts or app data. Reinstalling
does not merge old and new accounts automatically.

If setup says another installation is still running, close its setup window or
stop that Workspace and try again. If an unfinished update already has a recovery
copy, use **Open updates and recovery** first. Reinstall does not remove older
working recovery copies.
