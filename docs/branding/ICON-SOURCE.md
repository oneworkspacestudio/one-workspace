# Application artwork

The eleven application SVGs were supplied by the project owner in the
One Workspace SVG icon pack on 15 October 2026. Their transparent vector
artwork is preserved. PNG and ICO variants are generated by scripts/sync-branding.cjs.
The Workspace hub SVG was supplied separately by the project owner on the same
date. Its original gradients, tile arrangement and shadows are preserved in
the app, setup wizard, README and generated Windows resources.
