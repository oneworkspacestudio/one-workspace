# Application artwork

The project owner supplied the original application SVG pack and Workspace hub
artwork in October 2026. Later apps added their own project artwork. The source
history retains those originals.

At the owner's request on 20 October 2026, the collection was harmonised around
a dominant blue palette with mint and pale neutral accents. Recognisable symbols
were retained; Clips and Backups were redrawn as matching blue family members.
These are project-owned vector sources, not third-party product logos.

PNG/ICO variants are generated from `internal/branding/icons/` by
`scripts/sync-branding.cjs --local-only`. The complete README overview, table and
small-size gallery share `docs/branding/apps.json`. The overview is an icon
collection, not a screenshot of an application.
