# One Workspace showcase image

Generated with the built-in imagegen tool. The illustration is marketing artwork based on repository UI screenshots; it is not a literal screenshot or a statement that all apps ship in every installer. Existing SVG logos are unchanged.

The successful generation call supplied five references: the logo sheet, Drive, Office, Photos and Photo Editor. Music and Git windows are illustrative.

Final asset: `docs/images/one-workspace-showcase.png`.

Composition: premium software product launch image with a rich midnight-navy backdrop and very subtle cyan/violet atmospheric light. Use ample breathing room and controlled shadows, crisp edges, restrained gradients. Landscape 16:9 around 1920x1080. Main title in upper left, exact text "One Workspace", with smaller exact text "One account. Your apps, together." Beside title use a modest OW logo. Below and to the right, arrange six clearly separated but gracefully overlapping browser app windows in a balanced collage, front-facing with only very slight perspective. Depict original local file storage, document editing, photo browsing, image editing, repositories and music only. Visually cohesive but keep light file/document/gallery interfaces and dark editor/player interfaces.
App labels must be legible and exactly "Drive", "Office", "Photos", "Photo Editor", "Git", "Music"; use their corresponding MD MO MP PE MG MM square logos as small window-header identities. Avoid dense tiny readable paragraphs. No additional logos or invented icons, no external company brands, no claims about security, cloud sync, AI features or production readiness. Do not add a row/grid of standalone icon cards, no checkerboards, no repeated branding samples, no mock hardware, no tangled connectors, no faux browser URL bars with real hostnames.
