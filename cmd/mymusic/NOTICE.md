# Vuno notices

Vuno is part of One Workspace and uses its Apache-2.0 licence and apphost
runtime. The corresponding source and Go dependency declarations are included in
the One Workspace source archive.

ACE-Step 1.5 is a separately installed MIT-licensed music generation engine.
Its Python environment, model checkpoints, CUDA dependencies and weights are
supplied and licensed by their respective distributors. The Workspace package
includes an HTTP client for its local API.

DeepSeek is an optional external API. Vuno sends a brief to it when the
owner requests a lyrics draft or prompt refinement. No DeepSeek SDK or model
is distributed with this app.
