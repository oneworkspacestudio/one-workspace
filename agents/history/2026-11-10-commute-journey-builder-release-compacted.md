The authorized app-only release adds guided bus and train legs, per-direction
reordering, searchable multi-select with termini, and stop-to-stop ride timings.
Source `5b301343def4d71bb99f02b30ac8dca818c15ef1` is tagged
[v0.1.0-preview.3](https://github.com/oneworkspacestudio/my-commute/releases/tag/v0.1.0-preview.3).
All nine release assets and the anonymous archive download were verified.
The managed contract still requires preview.116 and `native-commute-v1`.

The release executable passed 11 browser scenarios. The isolated NTFS managed
fixture passed preview.2 to preview.3, rollback to preview.2, and reapply, with
saved journeys, preferences, MyAccounts, and the manager preserved.
The public channel promotion uses the standard index publisher's new Commute
entry and preserves every prior entry. Only the Commute component pin advances.
This is an independent app release using the existing manager integration.
No owner installation was requested for this release.
