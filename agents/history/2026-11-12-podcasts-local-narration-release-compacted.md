# Podcasts local narration release

The user reported a reviewed DeepSeek episode blocked by OpenAI speech on their
second PC. My Podcasts preview.6 uses My Voice preview.9 by default. The owner
issues a revocable stock narration grant in My Voice and saves it in Podcasts.
The existing My Voice process wakes an installed CPU model over its direct
loopback listener. Podcasts saves and resumes the three-times-daily schedule
and any previously reviewed scripts when the local connection becomes ready.

Managed source repositories are oneworkspacestudio/my-podcasts and
oneworkspacestudio/my-voice. Release sources are Podcasts 4e9e9e5 and Voice b928ecd.
Use existing native namespaces (48 and 116 files), routes, port offsets,
MyAccounts, storage and protected updater. No manager or Android build is
needed for these independent app updates. GitHub Actions stay disabled.

On isolated NTFS, real MOSS and Pocket CPU speech worked. The signed-out
worker recorded three scheduled WAVs and resumed one saved script with real
Pocket narration and synthetic text/research. Official Workspace preview.123
fresh setup, candidate two-app upgrade, OIDC, pairing, model readiness and
rollback were checked. The second PC and its provider credentials were not
used as test fixtures. New owner-PC deployment was outside this delivery.
