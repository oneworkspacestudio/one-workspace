## Implementation

folder-bound explicit Reinstall checkbox; stale reviews/edits reset it. Existing
entry also opens same-folder reinstall without demanding a new account password.
Recognised installations bypass new-account/domain forms and keep saved values.

Complete installations stage every replacement first, retain newer independent
apps by exact hash, keep selection/ports/credentials, and reuse journalled update
backup/recovery with an internal repair-only option. Force same-version file
replacement and stage a verified recovery controller even if manager is missing.
Normal updates still require all installed hashes. Repair snapshots can contain
broken/missing programs, so are RecoveryOnly with purpose repair; previous known
working backups remain. No ordinary cleanup of repair snapshots.

Incomplete trees are retained by same-volume directory moves into unique protected
ReinstallRecovery folders before fresh setup; ordinary Files untouched. Sign-in
starts anew, previous accounts/app data preserved in recovery, clearly stated in
wizard. Reject reparse paths, overlapping roots, stale tree, active install locks.
A parent setup lock serializes new installers and reinstall. No recursive delete
or arbitrary folder-emptying override is introduced.
