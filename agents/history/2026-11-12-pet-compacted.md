# Pet and Clover Hollow

Pet preview.1 is an optional Creative & Development app built in the
One Workspace repository. Worktree `I:/Projects/workspace-pet` branches
from current public main, apart from unrelated local changes in the older
Workspace checkout and the unborn outer aggregate.

The supervised Go service owns one shared habitat, adopted by the Workspace
owner. Authenticated visitors view and give treats. A two-second simulation
tick persists the whole snapshot transactionally in apphost SQLite and
replays up to eight hours with instincts after downtime. Care needs override
model activity suggestions. Day and rain affect needs and activity. Art,
sculptures and field notes have bounded storage. The AUI/React/Three.js
viewer is embedded in Pet.exe and needs no network assets or Node at runtime.

Managed ID pet, /pet, 9046, manager+56, private data pet, installer integration
16 and manager preview.124. AI modes are opt-in, using fixed loopback Ollama
or the rebased AI Service private port and an owner-issued pet credential.
Only simulation data goes to models. Keep apphost session checks, CSRF,
owner controls, private backup and the model action allowlist intact.

Pet, catalog, suite, distribution and apphost tests passed with synthetic
NTFS temporary data. The model tests use synthetic Ollama and AI Service
responses. A day of simulation tests all six activities, daylight, weather
and bounded collections. Standalone browser verification passed first-person
movement, mobile touch controls, camera follow, treat and cooldown at phone
and desktop widths. Go vet, publisher tests and npm production audit passed.
