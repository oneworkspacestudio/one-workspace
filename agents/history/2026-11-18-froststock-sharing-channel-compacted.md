# Froststock shared freezer release

Froststock preview.9 from b85731f adds owner-managed invitations for other
verified OneAccounts users on the same issuer. Shared users scan and edit
the same inventory. Owners manage sharing and the saved DeepSeek key.
The independent release retains the five package paths and minimum
Workspace140 contract. Public channel promotion is 9a1853d. Workspace141
continues as the current suite release.

Anonymous public checking and staging verified the three changed app files,
preserved the manager and unrelated app entries, and matched the accepted
release executable. A fresh synthetic NTFS Workspace140 Accounts/Drive
installation installed Froststock through the public updater, passed all
health checks, rolled back and reapplied while retaining manager, owner
and file root. Froststock's release executable also passed synthetic OIDC,
shared inventory/UI editing, old-data upgrade, restart and revocation browser
acceptance. Task-owned services were stopped. No owner install was requested.
